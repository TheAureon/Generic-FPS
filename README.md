# Generic FPS

A singleplayer first-person shooter that runs in your web browser. You fight AI bots that see, hear, take cover, retreat, and hunt you around the map.

Built with [Three.js](https://threejs.org/) (3D graphics) and [Vite](https://vitejs.dev/) (development server), in TypeScript. There are no image or audio files: the guns are low-poly 3D models (see [Credits](#credits)), everything else is built from simple shapes in code, and every sound is generated by code. The only other files bundled in are two fonts (Rajdhani for titles, numbers and the HUD; Inter for text), packed into the game file so they work offline.

- **New guns**: every gun is a real low-poly 3D model now, with working magazines, pistol slide, shotgun pump, sniper bolt and the LMG's flip-up feed cover, and iron sights that line up when you aim. Camos paint them too. See [Gun models](#gun-models).
- **Three new maps**: **Harbor** (a container dock at dusk), **Metro** (an underground train station) and **Outpost** (a desert village with roofs and bridges). See [Playing](#playing).

## How to play (Mac)

### Quickest: double-click `index.html`

Double-click **`index.html`** in the project folder. It opens in your browser at the title screen. You don't need Terminal or Node.js. (`Play.html` is an identical copy, kept so older links still work.)

`index.html` is the complete game in a single file. If you change `src/config.ts`, either play through the development server below, which shows your changes instantly, or run `npm run build` to rebuild `index.html` and `Play.html`.

### Putting it on a website

Upload **`index.html`** to any web host. It's the whole game in one file, with nothing else needed. When someone opens your site (or the folder you put it in), the game starts.

For **GitHub Pages**, go to the repository's **Settings → Pages**. Under "Build and deployment", choose "Deploy from a branch", pick this branch and the `/ (root)` folder, and save. The site serves `index.html` automatically.

### Development server (to tweak the game)

#### One-time setup

1. **Install Node.js.** Go to <https://nodejs.org>, download the **LTS** installer for macOS, and run it.
2. **Get the code.** Open the **Terminal** app (press Cmd+Space, type *Terminal*, press Enter) and paste:
   ```bash
   cd ~/Desktop
   git clone https://github.com/TheAureon/Generic-FPS.git Generic-FPS
   cd Generic-FPS
   git checkout claude/tender-rubin-0yqqrq
   ```
   If your Mac asks to install "command line developer tools", click **Install**, wait for it to finish, then paste the commands again.
3. **Install the game's libraries:**
   ```bash
   npm install
   ```

#### Every time you want to play

```bash
cd ~/Desktop/Generic-FPS
npm run dev
```

Your browser opens the game automatically. If it doesn't, open <http://localhost:5173/dev.html>.
To stop the server, click the Terminal window and press **Ctrl+C**.

#### Getting updates

```bash
cd ~/Desktop/Generic-FPS
git pull
npm install
```

Chrome is recommended. Safari and Firefox also work.

## Playing

The game opens on the title screen. Click or press any key to reach the main menu, where you can **Play**, read **How to play**, or open **Settings**. Click **Play**, choose your match, and click **Start**. Your choices are remembered for next time.

- **Mode**: one of twenty, in four tabs (below)
- **Map**:
  - **Foundry**: the main arena: two yards with raised decks around a two-story building
  - **Office**: a two-story office building with a parking lot. Ground floor: glass-fronted double-height lobby, corridor, private offices, meeting room, cubicle workspace, break room. Upper floor (two staircases): open office, executive office (armor), conference room, and a walkway with a glass railing over the lobby. Windows all round; you can see and shoot through glass, but not walk through it. The minimap shows the floor you're on.
  - **Museum**: a grand stone museum on a raised podium, inside a walled garden. The marble Grand Hall has columns, a glass skylight and two staircases up to a balcony (armor). Around it: a sculpture gallery (west), a painting gallery (east), antiquities with glass display cases (north) and a modern art gallery above them, plus the foyer, gift shop and café. Outside: front steps under a columned portico, a fountain plaza, hedge gardens, side paths and a service yard with a loading dock.
  - **Forest**: rolling wooded hills (180 × 180 m) with a stream winding through. A clearing with a log cabin you can enter, a wooden watchtower on a hill (armor on top), old stone ruins on another hill, a campsite with tents, and two footbridges (or wade across the stream). Dirt trails link them; pines, leafy trees, bushes, rocks and fallen logs everywhere else, and cliffs all round the edge. Crouch in a bush and bots can't see you (bullets still go through leaves).
  - **Mountain Plains**: wide grassy plains (210 × 210 m to play in) in a valley ringed by snow-capped mountains. A farm (farmhouse, a barn with a hayloft, a silo, a paddock, hay bales), a relay station with a radio mast on a hill (armor inside), a rocky ridge with a cliff face and boulders (great for the sniper rifle), a river with an old stone bridge, and a lake with a boathouse and jetty. Dry-stone walls between the fields make cover. You wade through the river and lake.
  - **Flatlands**: a huge (200 × 200 m), flat dusty plain with scattered cover, eight outposts (shipping containers, crates, low walls) and four corner towers with ramps. Long sightlines: good for the sniper rifle.
  - **Harbor**: a container dock at dusk (80 × 56 m, plus a pier). A yard of shipping containers in lanes, some stacked two high, with a metal staircase up onto the stacks and walkways between them (armor on top); a gantry crane over the yard; two big warehouses with roller doors, shelving and a mezzanine (armor in the west one); the quay with bollards, cargo, a fuel tank and the harbor office (a two-room cabin); and a wooden pier out over the water. Invisible rails stop you falling into the sea.
  - **Metro**: an underground train station (64 × 42 m). Two tiled platforms either side of a sunken track bed with two tracks; a train stands on the north track (walk in at its doors and out the other side, down onto the tracks); a glass footbridge over the tracks (armor on it) with stairs down to both platforms; service steps up out of the track bed at both ends; dark tunnel mouths with red lights. North: the ticket hall with a line of turnstiles, a kiosk, ticket machines and the stairs up to the closed street gate. South: a service corridor with an electrical room (armor). Close quarters everywhere.
  - **Outpost**: a walled desert village at midday (80 × 64 m). Flat-roofed sandstone houses you can go into, with outside stairs up to the roofs and plank bridges from roof to roof; a two-story lookout tower in the middle of the north row (armor upstairs), joined to a roof by a bridge; the market square in the middle with a well, stalls, carts and hay; ruined walls and a fuel dump at the ends.
  - **Test Room**: a small room for trying out movement
- **Difficulty**: eight levels, easiest first: Novice, Beginner, Easy, Medium, Advanced, Hard, Master, Insane. This changes how fast bots react, how accurately they aim, how fast they turn, how long their bursts are, how aggressive they are, and how much their bullets hurt (from about a third of yours on Novice up to the same as yours on Hard and Master). Bots never get more health, speed or ammo than you.
  - **Insane** is meant to be unfair. Bots react almost instantly and their aim barely wavers, even while you're moving. They aim at your head and fire long bursts with hardly a pause. They see almost all the way around them (only right behind them is safe), remember where you were for 30 seconds, and their bullets hit 40% harder than yours. Expect to die a lot; it pays ×5 XP.
- **Bots**: 1–10. In team modes you're on Blue with half of them (rounded down); Red gets the rest (e.g. 6 bots: you + 3 vs 3).
- **To win** (depends on the mode): Free for All kills (10/20/30), Team Deathmatch team kills (25/50/75), King of the Hill seconds (30/60/90), Court of the Hill team seconds (60/100/150), Capture the Flag captures (1/3/5), Control points (150/250/400)

### Game modes

Every mode has a 10-minute time limit (then the highest score wins). In team modes you're on **Blue**: your teammates wear blue, show their names above their heads and appear as blue dots on the radar; Red's wear red. There's no friendly fire (your bullets pass through teammates, and theirs through you). Each team spawns on its own side of the map. Hills, zones and flags are marked on screen (with their distance, pinned to the edge of the screen when they're out of view) and on the radar, and a bar under the score shows what's happening where you stand ("Capturing B", "You have the flag!").

- **Free for All**: everyone for themselves, bots included. First to the kill limit wins. Everyone respawns a few seconds after dying.
- **Team Deathmatch**: Blue against Red. Every kill scores for the killer's team; first team to the limit wins.
- **King of the Hill**: free for all around a glowing ring (the hill). While you're the only one in it, you score a point a second; if anyone else is in it too, it's contested and nobody scores. The hill moves to a new spot every minute.
- **Court of the Hill**: King of the Hill in teams: your team scores while only your team is in the hill.
- **Capture the Flag**: each team has a flag at its base. Walk into the Red flag to grab it, then bring it to your own base while your flag is safe at home. If the carrier dies, the flag drops: touch your own dropped flag to send it home (it also goes home by itself after 20 seconds). Bots attack, defend, escort carriers and chase yours down.
- **Control**: three zones, A, B and C. Stand in one with only your team in it to capture it (faster with more of you; an enemy zone has to be neutralized first). Each zone your team holds scores a point a second.
- **Battle Royale**: last one standing. Everyone has one life, and a safe zone (the blue wall) shrinks in four stages: outside it you lose health every second, more each stage. If you're eliminated you see where you placed.
- **Survival**: waves of bots hunt you. Wave 1 has the number of bots you chose, and each wave adds one (up to 12). Bots get faster and more accurate each wave until wave 6. You have one life, and clearing a wave gives you back 30 health. Your score is how many waves you survive.
- **Zombies** (co-op): you and two bot allies against endless waves of zombies (wave 1 has the number you chose, each wave 2 more, up to 14 on the map at once). Zombies have no guns: they glow a faint green, run at you with their arms out and claw (harder each wave); they also get tougher and faster every wave. You start with just the pistol. Hits (+10), kills (+60, +40 more for a headshot) and cleared waves earn points (shown as $ at the top). Spend them at stations around the map (walk up and press **F**): guns (SMG $500, Shotgun $750, Rifle $1,000, Sniper $1,250, LMG $1,500; buying one you already have refills your ammo for half price) and perk machines (**Tough Skin** $2,000: take 35% less damage; **Quick Feet** $1,500: move 12% faster; **Double Tap** $2,500: 40% more damage). If you go down, you're back at the start of the next wave as long as an ally is still standing; when everyone is down, it's over. Clearing wave 10 counts as a win.
  - **Barricades**: zombies come in through boarded-up windows on the walls (4 to start with). A zombie that arrives has to tear the boards off one by one before it can climb through (you can shoot it while it does). Stand at a barricade and hold **F** to put boards back (+10 points a board, up to 40 boards' worth of points a wave).
  - **Doors**: on maps with rooms behind doorways (Office, Museum, Harbor, Metro and Outpost), the game finds the doorways that close off part of the map from where you start and boards them shut with a door that has a price on it ($750, then $1,000, then $1,250). Walk up and press **F** to buy it open: the door slides away and the area behind it opens up, with one of the perk machines inside (and, if there's room, more barricades). Maps without such doorways (Foundry, Forest, Mountain Plains and Flatlands) have no doors; everything is open from the start. The doors and barricades are worked out from the map's walls when the match starts (`src/modes/zombieMap.ts`).
- **Arena Ladder**: 1v1 duels against one bot at a time: the Rookie (pistol), Brawler (SMG), Gunslinger (shotgun), Veteran (rifle), Elite (LMG), Master (sniper) and finally the Champion (rifle, between Master and Insane). First to 3, 5 or 7 kills wins a duel; lose one and your run ends. Beat all seven to become Arena Champion. (The difficulty setting doesn't apply: each opponent has its own.)

The match menu sorts the modes into tabs: **Classic**, **Party**, **Objective** and **Co-op & solo**.

**Party modes:**

- **Gun Game**: everyone starts with the SMG. Every kill (1, 2 or 3 per gun, your choice) moves you to the next gun: SMG → Assault Rifle → Shotgun → LMG → Sniper → Pistol. A kill with the pistol wins. Getting killed by a grenade or the katana (or your own grenade) knocks you back one gun. Each player carries one grenade per life.
- **Kill Confirmed** (teams): every death drops a spinning dog tag in the dead player's team color. Grab an enemy tag to confirm the kill (a point for your team, +50); grab a teammate's to deny the enemy theirs (+25). Tags vanish after 30 seconds (they blink at the end). Bots go for tags near them.
- **Infected**: everyone starts as a survivor. Six seconds in, one bot turns: the infected glow green, move 15% faster, carry only a shotgun and no grenades. Anyone they kill comes back infected, you included. Survivors win if anyone is still human when the clock (2, 3 or 5 minutes) runs out; you win with whichever side you're on at the end (+500 for surviving).
- **One in the Chamber**: a pistol with one bullet, and any hit kills. A kill gives you a bullet back. If you're empty for 10 seconds, a bullet comes back on its own (or go in close with the katana). No ammo pickups or grenades. You have 3, 5 or 7 lives; the last one with lives left wins.
- **Headhunter**: free for all where only headshot kills score (+50 each). The bots aim for heads in this mode.
- **Juggernaut**: five seconds in, one fighter becomes the Juggernaut: it glows orange, takes 30% of normal damage, moves 15% slower, and carries an LMG with plenty of ammo and no grenades. Everyone hunts it, and whoever kills it becomes the next one. Every second as the Juggernaut scores (+10 points a second for you); first to the limit wins. An orange **J** marks the Juggernaut.
- **Prop Hunt**: two rounds. First you hide: you're disguised as a prop (a barrel, crate, traffic cone, trash can or stack of tires), with no gun, while the bots wait 20 seconds and then search. A bot that gets a good look at you can spot you (much more likely if you're moving, and up close); then they all come shooting, until you stay out of sight for 8 seconds and they lose you. Survive 2 minutes to win the round. Then you seek: the screen goes dark for 20 seconds while the bots run off and turn into props among 28 decoy props. Shoot them to find them, but every shot that hits nothing costs you 3 health. Every 25 seconds a hidden prop whistles (a ♪ marker). Find them all in 2 minutes to win the round. Win at least one round to win the match.

**More objective modes** (teams):

- **Hardpoint**: one zone is live at a time, and it moves every minute (the next spot shows 10 seconds early, marked **Next**). Capture it like a Control zone (5 seconds); after that your team scores a point a second as long as no enemy stands in it. Enemies have to neutralize it, then capture it.
- **Search & Destroy**: rounds, one life each. The attackers plant the bomb by standing in site **A** or **B** for 4 seconds (with no defender in it); the defenders stop them or defuse the bomb by standing on it for 6 seconds before its 30-second timer runs out. Wiping out the other team also wins the round, and so does running out the 100-second clock as a defender. Sides swap every round; first to 3, 4 or 6 round wins takes the match.
- **Escort**: your team (Blue) pushes a cart along a route (drawn on the ground) from your side to theirs. It rolls while your team is within its ring and theirs isn't (faster with more of you), and rolls slowly back if nobody pushes for 8 seconds. Two checkpoints each add 45 seconds. Get it to the end before the clock (2, 3 or 4 minutes) runs out.

When a match ends, the scoreboard shows the result, your kills, deaths, and accuracy, with buttons to play again or return to the main menu.

### On screen

- **Bottom left**: health and armor bars (in 10 segments). When you're hit, a pale strip shows how much you just lost; health turns red when low.
- **Bottom right**: your six weapons (the one in hand highlighted with its name) and how many grenades you have, the weapon name, rounds in the magazine and spare rounds, a row of marks (one per round in the magazine), and a reload bar
- **Top left**: the minimap. It turns with you (up is the way you're facing; the **N** marker shows north) and shows walls, pickups, your view cone, and enemies you can see or that just fired. A triangle means the enemy is above or below you.
- **Top center**: score, leader, and time left (or wave and enemies left)
- **Top right**: kill feed (your kills in gold, your deaths in red, a target icon for headshots)
- **Middle**: crosshair (spreads out when your shots are less accurate), hit markers (white = hit, gold = headshot, red = kill), short notices (reloading, low ammo), and a red arc pointing toward whoever is shooting you
- **When you die**: who killed you and a countdown ring until you respawn
- **Hold Tab**: the scoreboard, with kills, deaths and K/D

### Score, medals, streaks and levels

Every hit shows a **damage number** rising from where the bullet landed (gold for a headshot, red for the killing blow). Every kill flashes the screen edges gold and pops up your points next to the crosshair: +100 for the kill, plus any bonuses:

| Bonus | For | Points |
|-------|-----|--------|
| Headshot | Killing with a shot to the head | +50 |
| First Blood | The first kill of the match | +75 |
| Longshot / Point Blank | A kill from 35 m or more / at arm's length | +50 / +25 |
| Close Call | A kill while you're on 25 health or less | +50 |
| Revenge | Killing whoever last killed you | +50 |
| Comeback | A kill after dying 3 times in a row | +75 |
| Buzzkill | Ending an enemy's streak of 3 or more | +100 |
| Collateral | Two kills with one shot | +100 |
| Avenger | Killing an enemy who just killed a teammate | +50 |
| Frag Out | A kill with a grenade | +50 |
| Double / Triple / Quad Kill / Rampage | 2 / 3 / 4 / 5+ kills, each within 4.5 seconds of the last | +100 / +200 / +350 / +500 |
| On a Roll / Killing Spree / Unstoppable / Godlike / Legendary | 3 / 5 / 8 / 12 / 16 kills without dying | +100 / +200 / +350 / +500 / +750 |

Bonuses also pop up as **medals** (bronze, silver, gold and purple), and the big ones (multikills, streaks, First Blood, Collateral, Buzzkill) get a call-out across the screen with its own sound. Above your health, a badge shows your score this match and, from 2 kills in a row, your streak (it catches fire at 5).

At the end of a match, the **match report** counts up your score, kills, deaths, K/D, accuracy, headshot kills, damage, best streak, longest kill and time, lists your medals, shows XP earned (your score, plus 200 for finishing and 500 for winning, then multiplied by the difficulty) and kills by weapon, then fills your **XP bar**, with a fanfare for each level you gain. The full scoreboard is folded underneath.

**XP depends on the difficulty**: none on Novice and Beginner (practice freely), ×1 on Easy, ×1.25 on Medium, ×1.5 on Advanced, ×2 on Hard, ×3 on Master and ×5 on Insane. The match setup screen shows each level's multiplier next to its description. Novice and Beginner are practice: matches played on them don't count toward your career stats either (matches, wins, kills, medals, best streak).

Your **level, rank** (Recruit, Private, Corporal... up to Legend, a new rank every 3 levels) and career stats show on a card on the main menu. They're saved in your browser, so they're still there next time (unless you use a private window or clear the browser's site data). The numbers are in `REWARDS` in `src/config.ts`.

### Weapons

| Key | Weapon | Good for |
|-----|--------|----------|
| 1 | Pistol | A quick backup; accurate single shots |
| 2 | Assault Rifle | All-rounder at most distances |
| 3 | Shotgun | Devastating up close, useless far away |
| 4 | Sniper Rifle | One-shot headshots at long range (scope) |
| 5 | SMG | Very fast fire, accurate while moving; weak at range |
| 6 | LMG | A 100-round box magazine for holding a lane; heavy (you walk 15% slower with it, and it's slow to raise and reload) |
| G | Frag grenade | Clearing corners and groups behind cover |
| V | Katana | A silent one-hit kill up close, without switching guns |

**Grenades**: you carry 2 (up to 4; ammo pickups give one more). Press **G** to lob one where you're aiming; it bounces off walls and floors and goes off after about 2 seconds, with a blinking red light while the fuse runs. The blast hurts everyone within 7 m who isn't behind cover, the more the closer they are, including you (at half strength). A red **!** marker warns you when a live grenade lands near you.

**Katana**: press **V** any time, whatever gun you're holding, and your gun dips while you draw the katana and slash diagonally across the screen. It kills anyone in one hit (the Juggernaut takes three, and zombies from wave 4 on take two), reaching about 2.6 m. You don't have to aim exactly: it finds an enemy within about 35° of your crosshair. It makes no gunshot, so bots don't hear it. A slash takes half a second, during which you can't shoot. A katana kill earns the **Sliced** medal (+50), and in Gun Game it knocks the victim back a gun. Its numbers (damage, reach, speed) are in `MELEE` in `src/config.ts`.

#### Gun models

Every gun is a low-poly 3D model. The pistol, assault rifle, shotgun, sniper rifle and SMG are downloaded models that came as one solid piece each, so they were cut up to animate. The LMG was built for this game from a reference picture (a belt-fed machine gun with a stock of two rods, a green ammo box and a belt of rounds running into its side):

- **Magazines** come out and go back in with your left hand when you reload (the pistol's grip had no separate magazine, so one was added inside it, with a base plate showing underneath).
- The **pistol slide** racks back at the end of a reload, the **shotgun pump** slides back and forward after each shot, and the **sniper bolt** turns up, slides back and forward again.
- **LMG reload**: your left hand flips the feed cover up, pulls the ammo box off, hangs a full one on, and slams the cover shut.
- **Aiming** lines up each gun's real sights: the pistol's rear notch and front post (the solid rear sight was given a notch), the rifle's front post in the middle of its rear ring, the shotgun's brass bead, new iron sights on the SMG (it had only a rail), and, on the LMG, the front post seen over the top rail. The sniper uses its scope.
- **Camos** cover them like the old guns, and the bots carry the same models.

The finished models are in `src/assets/models/weapons/`. They're made from the downloaded originals in `scripts/weapon-sources/` by `node scripts/bake-weapons.mjs`, which turns and sizes them, cuts out the moving parts, and adds the sight and hand points (all the settings are at the top of that file). The LMG is built by `node scripts/build-lmg.mjs`, where each piece is traced in pixels of the reference picture.

**Bots** carry an assault rifle, SMG or LMG (they take turns through the list in `BOTS.weapons`), and each has one grenade per life, which it may lob at you from 9 to 26 m away. Bots that notice a grenade near them run from it; on the easier levels they're slower to notice. Grenade kills earn the **Frag Out** medal.

### Records, map stars and achievements

- **Personal bests**: your best score, kills, streak, longest kill, damage, multikill and accuracy (with 10+ kills) in a single match. Beat one and the match report marks it **New best!**
- **Map stars**: ★ for winning on a map, ★★ for winning on Hard or harder, ★★★ for winning on Master or Insane. They show on the map cards when you set up a match.
- **Survival records**: your most waves cleared on each map (shown on the map cards when Survival is picked). Clearing waves 5, 10, 15 and 20 earns the **Survivor**, **Last Stand**, **Unbreakable** and **Immortal** medals with bonus points.
- **Achievements**: 44 career milestones, from *Centurion* (100 kills) and *Tourist* (finish a match on every map) to *Flawless* (win with 10+ kills and no deaths), *Jack of All Trades* (win every classic mode), *Life of the Party* (win every party mode), *Mission Specialist* (win Hardpoint, Search & Destroy and Escort), *Undead Slayer* (clear wave 10 in Zombies), *Arena Champion* (beat the whole Arena Ladder) and *All-Star* (every star on all nine maps). Each is earned once and gives XP: 500 (bronze), 1,000 (silver), 2,500 (gold) or 5,000 (legendary). The list is in `src/core/Achievements.ts`.

Like XP, none of this counts on Novice or Beginner.

### Career: unlocks, weapon mastery and prestige

Open **Career** from the main menu.

- **Armory**: each gun has a **mastery** level from your kills with it (10, 25, 50, 100, 150, 225, 300, 400, 500 and 650 kills). Mastery 2, 4, 6 and 8 unlock that gun's **Woodland**, **Desert**, **Digital** and **Tiger** camos, and mastery 10 unlocks **Gold**. Your level unlocks camos for every gun: Arctic (5), Crimson (10), Carbon (15), Cobalt (20), Neon (25, it glows), Obsidian (30) and Royal (50). **Prestige** and **Diamond** (gold on every gun) are special. Pick a camo per gun.
- **Look**: glove colors, crosshair styles (Classic, Dot, Circle, Cross, T) and colors, and the **menu backdrop** (Dusk, Night, Dawn, Storm, Golden Hour).
- **Profile**: your **calling card** (the background of your player card), a **title** (any achievement you've earned) and **prestige**.
- **Medals**: your medal collection: every medal with how many times you've earned it, unearned ones as silhouettes, and how many of each color you have. Collecting every bronze, silver, gold or legendary medal (and then every medal) earns achievements, and the last one unlocks the **Collector** calling card.
- **Achievements**: all of them, earned (with the date) or locked, and their XP.
- **Records**: your personal bests, career totals, and each map's stars, survival best and matches played.
- **Challenges**: today's and this week's challenges.

Unlocks come roughly one per level up to 50 (the next one is always a level or two away), from weapon mastery, from achievements and from prestige. They only change how things look. Locked items show what unlocks them, and the match report lists anything new you unlocked.

**Prestige**: at level 50 you can start over at level 1 (click twice to confirm). You get a prestige star on your emblem (up to 10), the Prestige camo, card and gloves, and the *Prestige* achievement. You keep everything you've unlocked, your stats, and your total (lifetime) XP, which is what the UsForge leaderboard shows. What you've equipped is saved in your browser.

### Daily and weekly challenges

**Weekly challenges**: three more each week (new every Monday), bigger versions of the daily ones (4× the target, e.g. "Get 160 kills"), worth **2,500**, **4,000** and **6,000 XP**. They show in the same places as the daily ones, tagged *Weekly*.

Every day you get three new challenges, one each of **Easy (+400 XP)**, **Medium (+800 XP)** and **Hard (+1,500 XP)**, for example "Get 8 kills with the SMG", "Win a King of the Hill match", "Get 3 grenade kills" or "Get an 8-kill streak in one match". Everyone gets the same three on the same day, and they change at midnight.

- The **main menu** shows today's challenges, your progress, and how long until new ones.
- **During a match** a small tracker on the right shows your progress live (it pulses when it goes up), and a banner pops up with a chime when you complete one.
- The **match report** shows how far the match moved each challenge, and their bonus XP is added to your XP (it isn't multiplied by the difficulty).
- Progress builds up over several matches and is kept if you quit or restart a match early. It's saved in your browser.
- Matches on Novice and Beginner (practice) don't count.

The XP per challenge is in `CHALLENGES` in `src/config.ts`; the list of challenges is in `src/core/Challenges.ts`.

### UsForge leaderboard

When the game runs on UsForge (inside its page), the end of each finished match sends your **total XP** (your career XP, the same number behind your level) to UsForge's top-10 leaderboard; UsForge asks for your nickname. Matches on Novice and Beginner (practice, no XP) don't post. Opened on its own, the game never sends anything. This is in `src/core/usforge.ts`, called from `endMatch` in `src/core/Game.ts`.

### Music

The game has its own music, composed in code like the sound effects (no audio files): a three-minute menu theme in D minor (an intro, a build-up with a rising arpeggio, a melody with soft drums, a full section with the melody an octave up and drum fills, a dark breakdown with bells, and back again), and quiet ambience during a match that builds up when you're in a fight (bass, drums, then a fast arpeggio) and calms down a while after. It dips under explosions, big call-outs and completed challenges, gets quieter while paused, and the end screen plays a short victory or defeat stinger. There are two styles to choose from in **Settings → Music style**:

- **Synth** (the default): the pads, arpeggios and electronic drums described above.
- **Cinematic**: an orchestra made in code. The menu piece plays the same theme in C minor with string sections, horns, a choir, harp, taiko drums, timpani and cymbal swells; match music is tense low strings that build into driving short string notes, taiko and brass stabs when you're fighting; and the end screen gets a brass fanfare or a dark low fall.

Changing the style while music is playing crossfades to the other one. Set the volume in **Settings → Music** (all the way down = off; it starts at 40%). **Music in matches** is off by default, so while you play you only hear the game (footsteps, gunfire, where shots come from); turn it on in Settings to get the match music. It's in `src/audio/Music.ts`, where the chords and tempo of each track are at the top.

### Pickups

Walk over a pickup to grab it. Each one comes back 20–30 seconds after it's taken.

- **Health** (white case, red cross): +35 health
- **Armor** (blue vest, on the Foundry roof): +50 armor. Armor soaks up 60% of each hit until it runs out.
- **Ammo** (ammo can): two spare magazines for every gun, plus a grenade

Bots use pickups too: hurt bots go for health, and bots have the same ammo as you (a full magazine plus the same spare rounds, refilled by ammo pickups), so they have to fetch ammo when they run low. Bots don't wear armor.

### Settings

Open **Settings** from the main menu or the pause menu. Changes are saved automatically.

- **Mouse sensitivity**, **Field of view**, **Volume**, **Music** (all the way down turns it off), **Music style** (Synth or Cinematic), **Music in matches** (off by default)
- **Screen shake**: on or off
- **HUD size**: shrink the on-screen panels (health, ammo, minimap, kill feed, status bar) down to 60%. The crosshair always stays the same size.
- **Aim / scope**: which button aims down sights and scopes: **Both** right mouse and Q (default), only the right mouse button, or only Q.
- **Graphics**: Low, Medium, or High. If the game feels choppy, try Medium or Low. Some changes take full effect from the next match.
  - **Low**: no shadows, simpler (cheaper) surface shading, lower resolution, and flat painted textures instead of 3D bricks and concrete panels. Helps most on Retina screens.
  - **Medium**: shadows, faint reflections on metal and armor, surface relief on every texture (bricks, bark, stone, planks, grass look raised, not painted on), real 3D bricks, concrete panels, stone blocks, logs and boards on the walls, baseboards along painted walls, leafy trees and bushes (made of many leaf clusters instead of solid shapes), grass tufts and wild flowers on the hills and lawns, and color grading (warm sunlit highlights, softly tinted shadows and a gentle darkening toward the screen edges, matched to each map's sky).
  - **High**: all of that, plus full resolution, sharper soft-edged shadows, ambient occlusion (soft shading where things meet: room corners, under furniture, around feet) and a glow ("bloom") around lamps, visors, and muzzle flashes.

  The map is detailed on every setting: the floor is industrial concrete slabs (each a little different, with joints, stains and hairline cracks), the steel ramps have diamond-plate tread, anti-slip cleats, edge rails, side beams and support posts, wooden crates have frames, braces and planks, and the yellow barriers are sloped jersey barriers in sections. On Medium and High the brick walls are built from individual 3D bricks (with mortar between them), the concrete walls from cast panels with seams and form-tie holes, the museum's sandstone walls from raised blocks, the ruins and field walls from rough uneven stones, the log cabin from stacked round logs (their ends sticking out at the corners), and the barn from vertical boards. Water is glossy, slightly see-through and gently moving.

  Furniture and objects are real models, not boxes: desks with legs and drawers, office chairs on five-star bases, cubicle panels, monitors, sofas, bookshelves full of books, counters, a vending machine and fridge, café tables and bistro chairs, cars with tinted windows and wheels, lamp posts, planters, park benches, dumpsters, air conditioners; fluted marble columns, statues in different poses, a knot sculpture, framed paintings, display cases with gold treasures, a sarcophagus, an obelisk, a round fountain, leafy hedges and an iron gate; ridge tents, a picnic table, a woodpile, a wood stove, bunk beds, round wooden posts, square and round hay bales, a corrugated silo, fuel tanks, a feed trough and an upturned rowing boat. What you bump into and shoot is still the same simple box underneath.

  The sky is drawn by a small shader: a gradient from the horizon up, the sun with a soft glow, and slowly drifting clouds, with distant factory buildings and smokestacks fading into the haze beyond the walls. The sun in the sky is where the sunlight (and shadows) come from, the light from the sky is tinted like the sky, and on Medium and High metal and armor reflect the sky. Foundry is set in the late afternoon (warm, low sun, long shadows); the menu background is at dusk, with lit windows in the distance. Each map's sky is set in its map file (`sky:` with colors, sun position, cloud cover).

  On every setting the map has **baked lighting**: when a map loads, the game works out once how dark each corner is and how much light each wall lamp throws, and paints that onto the surfaces. That looks like many lights but costs almost nothing while playing. On Medium and High it also works out **bounced sunlight**: sunlit floors and walls throw a little warm light into nearby shade (under porches, into doorways and rooms with windows), and lamps get a soft glow halo. On the big outdoor maps the sun's shadows follow you, so they stay sharp wherever you are.

  Every window has a frame (wood on wooden buildings, dark painted steel on stone, aluminium elsewhere), with mullions on wide windows and a sill. Doorways have frames, and narrow doors in houses and offices have an open door standing against the wall. Shipping containers (Flatlands, Mountains, Museum) have ridged steel walls, cargo doors with locking bars, a frame and corner fittings, each in its own color. Soldiers pick up the color of lamps they walk past the same way, and so does the gun in your hands.

## The soldiers

Bots are low-poly soldiers (helmet with a glowing visor, armored vest, backpack, team-colored shoulder pads) with a real skeleton, drawn as a single mesh so many bots stay cheap. All animation is done in code:

- legs walk or run in the direction they move (including strafing and backing up) while the upper body keeps aiming at you
- both hands stay on the rifle, with elbows bending naturally; the gun kicks when they fire
- they flinch when hit, tilt the rifle and swap the magazine when reloading, tuck their legs when jumping, take small steps when turning on the spot, and breathe and shift weight when standing
- when killed they crumple and fall away from the shot (a headshot snaps the head back) and drop their gun

The model is in `src/assets/characterModel.ts` and the animation in `src/bots/CharacterAnimator.ts`.

In first person you see your own arms holding each gun: sleeves and dark tactical gloves (knuckle guard, padded palm and fingertips, curled fingers and thumb, and a cuff with a strap). They follow every bob, sway and recoil. When reloading, the gun tilts and your left hand pulls the magazine out, drops out of view for a fresh one, pushes it in and slaps it home (the shotgun instead loads shells one at a time). The pistol finishes its reload by turning side-on while your left hand racks the slide back and lets it snap forward. After each shotgun blast your left hand racks the pump back, the spent shell flies out, and the pump slides forward again. After each sniper shot your right hand works the bolt (up, back, the case flies out, forward, down); the scope comes off while you do, and goes back on by itself if you're still holding the aim button. This is in `src/weapons/ViewmodelArms.ts`.

## How the bots work

Each bot has:

- **Vision**: a 120° view cone, a 60 m range, and line of sight. Bots can't see or shoot through walls.
- **Hearing**: they hear gunshots within each gun's hearing range, and they know roughly where a shot came from when they're hit.
- **Imperfect aim**: a reaction time before they start shooting, a limited turn speed, and aim that wobbles more with distance, when you move, and when they move. Their aim settles the longer they track you.
- **Navigation**: when a map loads, the game scans it for every spot a bot can stand on, on every level, and links spots a bot can walk between, including ramps and drops off ledges. Bots plan routes over this graph, so they walk around walls instead of into them. Press **B** in-game to see it.

Each bot runs a state machine (`src/bots/BotBrain.ts`). Press **B** to see each bot's state above its head:

| State       | What the bot does |
| ----------- | ----------------- |
| patrol      | Walks between random spots, pausing to look around (and grabs health if hurt, or ammo if low) |
| investigate | Heard a gunshot or was shot by someone it can't see: turns and goes to check |
| attack      | Sees an enemy: aims, fires in bursts, strafes, keeps its distance |
| cover       | Under fire: runs to a nearby spot the enemy can't see, reloads, then peeks out |
| retreat     | Low on health: runs to health or to a hidden spot, firing back if cornered |
| resupply    | Out of ammo (or low, with ammo nearby): goes to an ammo pickup, shooting back with what's left; if it's been taken, waits for it to come back |
| chase       | Lost sight of the enemy: goes to where it was last seen |
| search      | Found nothing there: checks a few places nearby, then patrols again |

## Tweaking the game

**All the gameplay numbers are in one file: [`src/config.ts`](src/config.ts).** Each one has a comment explaining it. While `npm run dev` is running, save the file and the game reloads with the new values.

| Section          | What it controls |
| ---------------- | ---------------- |
| `CONFIG.player`  | Movement speeds, jump, gravity, crouch, health, armor, respawn time |
| `CONFIG.camera`  | Sprint zoom, head bob, screen shake strength |
| `WEAPONS`        | Each gun's damage, headshot bonus, fire rate, magazine, reload time, spread, recoil, zoom, range, walking speed |
| `COMBAT`         | Aiming slowdown, crouch accuracy bonus |
| `BOTS`           | Bot speed, health, vision range and angle, memory, preferred fighting distance, names, and the guns they carry (`weapons`) |
| `CHALLENGES`     | Bonus XP for easy, medium and hard daily and weekly challenges |
| `GRENADES`       | How many grenades you carry, fuse time, throw strength, blast damage and radius |
| `BOT_DIFFICULTY` | Novice … Insane: reaction time, aim error, turn speed, bursts, aggression, damage, plus Insane's extras (head aim, view cone, memory) (`DIFFICULTIES` holds the names and menu descriptions) |
| `MATCH`          | Menu defaults, Free for All kill limits, the time limit |
| `TEAMS`          | Team names and colors |
| `MODES`          | Each mode's win targets, hill size and how often it moves, flag return time, zone capture time, the Battle Royale zone stages |
| `SURVIVAL`       | Wave growth, break between waves, health on wave clear |
| `PICKUPS`        | How much pickups give and how long they take to come back |
| `CONFIG.quality` | What Low / Medium / High graphics mean |
| `REWARDS` | Points for kills and medals, multikill time window, longshot distance, XP per difficulty, XP per level |

Examples:
- To make bots slower to react on Medium, raise `BOT_DIFFICULTY.medium.reactionTime`, for example to `0.7`.
- To make the shotgun stronger, raise `WEAPONS.shotgun.damage`.
- For longer matches, raise `MATCH.timeLimitMinutes`.

### Adding a map

Maps are plain data in [`src/map/maps/`](src/map/maps/). Each map is a list of boxes (walls, floors, crates) and ramps, with positions and sizes in meters, plus spawn points and pickup spots.

1. Copy `foundry.ts` (the arena) or `testRoom.ts` (a small room) to a new file and give it a new `id` and `name`.
2. Change the boxes, ramps, spawns, and pickups. Materials: `floor`, `wall` (brick), `concrete`, `crate`, `metal`, `trim` (jersey barrier), `dirt` (outdoor ground), `container` (shipping container).
   Indoor materials: `carpet`, `tile`, `drywall`, `ceiling`, `desk`, `partition`, `glass` (see and shoot through, can't walk through), `stairs` (on a ramp: shows steps). Town: `asphalt`, `paint`, `carpaint`. Museum and gardens: `marble`, `stone` (stone blocks), `grass`, `hedge`, `water`, `art` (paintings), `gold`, `velvet`. Forest and mountains: `forest` (forest floor), `rock`, `bark`, `timber` (log walls), `canvas` (tents), `ruin` (old mossy stone), `snow`, `hay`, `planks` (wooden boards), `barnwood` (red barn boards). A box can have different materials per side with `faces` (e.g. concrete outside, `drywall` inside). To draw a box as a detailed model instead, give it `model` (e.g. `model: 'car'`, with `tint` for the paint and `rot` to turn it): the list of models is at the top of `src/map/models.ts`.
   Buildings you can enter: set `indoorShading` (rooms get darker and are lit by their lamps and the windows) and `levels` (the floor heights, for the minimap). See `museum.ts`, which uses the helpers in `src/map/kit.ts` (walls with doors and windows cut in, floor slabs, stairs, lamps).
   Hills: give the map a `terrain` (made with `makeTerrain` from a height function; `src/map/terrain.ts` has noise helpers for natural hills) and `props` (trees, bushes, rocks, logs, stumps, placed on the ground automatically). Steep slopes become rock and can't be walked up. `hidden: true` on a box makes an invisible wall; `decor: true` on a box or ramp makes it see-only (e.g. water you wade through). Terrain `snowLine` puts snow on high ground. For far-off scenery (mountains you can see but not reach), make the terrain bigger and set `playArea`: invisible walls go around it and bots stay inside. See `forest.ts` and `mountains.ts`.
   For a very big map, set `navSpacing: 2` so the bots' navigation grid is coarser and the map loads quickly (see `flatlands.ts`, which also shows how to place cover with a fixed random seed).
   Game-mode objectives (hills, Control zones, flag bases) are placed automatically between the two ends of the map; to choose them yourself, set `objectives` (see `office.ts` and `museum.ts`).
3. Add it to the list in `src/map/maps/index.ts`.

It appears in the match menu automatically, and bots can navigate it without any extra work.

### Swapping in real art and sound

- **Sounds**: put audio files in a `public/sounds/` folder and list them in `SAMPLE_FILES` at the top of [`src/audio/sounds.ts`](src/audio/sounds.ts), for example `shot_rifle: '/sounds/rifle.wav'`. A file replaces the generated sound with the same name.
- **Gun models**: drop `.glb` files named `pistol.glb`, `rifle.glb`, `shotgun.glb`, `sniper.glb`, `smg.glb` or `lmg.glb` into [`src/assets/models/weapons/`](src/assets/models/weapons/) and they replace the built-in guns automatically (in your hands and the bots'). A model that comes as one solid piece can be prepared with `scripts/bake-weapons.mjs` instead (see [Gun models](#gun-models)). [`src/assets/models/README.md`](src/assets/models/README.md) explains how to export them and which named parts (sight, grips, magazine, slide, pump, bolt) make the hands and animations line up. Size and rotation fixes go in `WEAPON_MODELS` in [`src/config.ts`](src/config.ts).
- **Gun animations**: every first-person animation setting (gun position, hand positions, reload keyframes, pump/bolt/slide timing) is in [`src/weapons/animations.ts`](src/weapons/animations.ts).
- **Other models**: the character and pickup models are each made in one function in [`src/assets/`](src/assets/) (`createCharacterModel`, `createPickupModel`). Replace a function's contents to load a real 3D model instead. The comment at the top of each file explains what the rest of the game expects.
- **Textures**: wall and floor textures are drawn in [`src/assets/materials.ts`](src/assets/materials.ts). Swap in image files there.

## Troubleshooting

- **A page of text instead of the game**: that's `dev.html`, the development page. Open `index.html` instead, or use `npm run dev`.
- **The mouse isn't captured / "Click Resume"**: browsers only capture the mouse right after a click, and they refuse if you press Esc and click again very quickly. Wait a second and click **Resume**.
- **The game feels choppy**: Settings → Graphics → Medium or Low.
- **The sound stops**: press any key or click; the browser sometimes pauses a page's sound (for example when you switch to headphones or the computer wakes from sleep), and the game starts it again on your next key press or click.
- **No sound**: check the volume in Settings and your Mac's volume. Browsers only allow sound after your first click in the page.
- **`npm` isn't found in Terminal**: install Node.js (see setup above), then open a new Terminal window.

```
src/
  config.ts       All tunable numbers
  main.ts         Starts the game (loaded by dev.html)
  core/           Game loop and screens (Game.ts), one match (Match.ts), input, settings,
                  collision, walking physics, events
  player/         Player movement and camera (PlayerController), health and armor (Player)
  bots/           Bot body (Bot), senses (Perception), aim (BotAim), state machine (BotBrain),
                  navigation (NavGraph, Navigator), spawning (BotManager), animation
                  (CharacterAnimator), debug view
  weapons/        Weapon stats/state, bullet tracing (hitscan), firing and switching
                  (WeaponSystem), the gun and arms in your hands (Viewmodel, ViewmodelArms),
                  and all their animation settings (animations.ts)
  modes/          The game modes' rules (one file each), plus objectives.ts: where hills,
                  zones and flags go, and how they look
  pickups/        Health, armor, and ammo pickups
  map/            Map format, map builder (incl. baked lighting), 3D detail (bricks, panels,
                  crates, barriers), and maps/ (the map data)
  render/         Graphics quality, shader tweaks, and the bloom/reflection pipeline
  effects/        Tracers, sparks, bullet holes, muzzle flashes
  audio/          Sound engine and generated sound effects
  ui/             HUD, minimap, menus (title screen, main menu, setup, pause, settings,
                  end screen), the animated menu background (MenuBackdrop), styles, fonts
  assets/         Textures and models (made in code); models/weapons/ holds the gun models (.glb)
  entities/       Practice dummies (optional, per map)
scripts/
  bake-weapons.mjs   Prepares downloaded gun models for the game (see Gun models)
  build-lmg.mjs      Builds the LMG model from simple shapes
  weapon-sources/    The original downloaded gun models
```
